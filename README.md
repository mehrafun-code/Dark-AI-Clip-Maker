# AI Clip Maker (OpusClip jaisa)

## Install (Windows, sirf pehli baar)
1. Python 3.10+ install karo (python.org) — "Add to PATH" tick karo.
2. FFmpeg install karo: Command Prompt mein `winget install ffmpeg`, phir CMD band karke dobara kholo.
3. `run.bat` par double click.

Browser mein app khul jayegi.

## Notes
- API key na ho to bhi chalta hai (simple scoring), lekin AI se clips behtar milte hain.
- GPU (NVIDIA) ho to Device = cuda chuno, bohat tez hoga.
- Sirf apni ya permission wali videos use karo (copyright).
